38def bind_log_scope(func): 

39 """ 

40 包装一个将在其它线程执行的函数，使其日志归属调用本函数的线程。 

41 

42 必须在提交任务的线程里调用：作用域在包装时确定，辅助线程再启动的线程 

43 也会归到最初的任务线程。执行结束后解除绑定，因为线程 ID 会被系统复用， 

44 残留映射会把之后无关线程的日志算进已经结束的任务。 

45 """

56 _log_scope_roots[thread_id] = root_thread_id

71def _project_relative_path(file_path): 

72 """ 

73 把绝对路径缩短为 ``./`` 开头、始终使用正斜杠的项目相对路径。 

74 

75 Windows 上项目可能通过映射网络盘或 ``subst`` 盘启动。此时调用栈里的路径 

76 仍是 ``X:\\MoneyPrinterTurbo\\...``，而 ``PROJECT_ROOT`` 经 ``realpath`` 

77 解析后落在 ``C:\\...``，``os.path.relpath`` 会直接抛出 ``ValueError``。 

78 格式化函数抛错会被 loguru 捕获并丢弃整条记录，终端和 WebUI 日志面板会 

79 同时变空，因此这里必须兜底返回原始路径。项目目录之外的文件同理：把 

80 ``./`` 拼到 ``..`` 回溯路径上只会得到更难读的结果。 

81 """ 

82 try: 

83 relative_path = os.path.relpath(file_path, PROJECT_ROOT) 

84 except ValueError: 

85 return file_path 

86 if relative_path == os.pardir or relative_path.startswith(os.pardir + os.sep): 

87 return file_path 

88 # Windows 的 relpath 返回反斜杠分隔的路径，直接拼接会得到 ``./app\\utils`` 

89 # 这种混合分隔符的输出，与其它平台的日志不一致。 

90 return f"./{relative_path.replace(os.sep, '/')}"
