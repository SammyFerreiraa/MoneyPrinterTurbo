526def normalize_provider_override(value: str | None, default_value: str | None) -> str: 

527 """ 

528 只保留与 Registry 默认值不同的用户覆盖值。 

529 

530 WebUI 需要把默认值展示在输入框中，但不能因此把默认值固化到 config.toml； 

531 否则后续升级 Registry 默认模型或地址时，旧配置会继续覆盖新默认值。 

532 """ 

533 normalized_value = (value or "").strip() 

534 normalized_default = (default_value or "").strip() 

535 if normalized_value == normalized_default: 

536 return "" 

537 return normalized_value
